### 📱 App Android de Movilidad Inteligente
**Status**: Completado | Colaborativo (4 personas)

Aplicación Android nativa para calcular rutas optimizadas y estimar costes de desplazamiento según tipo de vehículo y consumo energético.

**Tech Stack:**
- **Mobile**: Kotlin + Jetpack Compose
- **Persistencia**: Firebase Firestore + Firebase Auth
- **APIs**: Google Maps, OpenRouteService, APIs de costes
- **Testing**: Kotest (ATDD)
- **Architecture**: MVVM + Coroutines

**Highlights:**
- Integración con múltiples APIs externas
- Diseño moderno con Material Design
- Autenticación y sincronización en tiempo real
- Testing completo con metodología Acceptance Test Driven Development
- Operaciones asíncronas fluidas con Coroutines
