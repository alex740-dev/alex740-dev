# Alejandro Illueca

Soy desarrollador full stack y trabajo principalmente en aplicaciones web empresariales vinculadas a SAP Business One.

Actualmente desarrollo y mantengo soluciones con VB.NET, .NET Framework, PHP y CodeIgniter, trabajando con lógica de negocio, procesos empresariales y datos procedentes de Microsoft SQL Server y SAP HANA.

## En qué estoy centrado

Me interesa el desarrollo de software aplicado a procesos reales de negocio: entender cómo funciona un proceso, trasladarlo a una aplicación y mantener la solución a medida que cambian las necesidades.

Gran parte de mi trabajo consiste en añadir funcionalidades, resolver incidencias y evolucionar aplicaciones existentes procurando que el código siga siendo claro y mantenible.
